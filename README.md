# Life Ledger

A private family app for capturing achievements, activities and reflections as they happen, so college applications, recommendation letters, CVs and interviews draw on confirmed evidence instead of memory.

- Spec (source of truth): `docs/feature-doc-v2.md`
- Build kickoff prompt: `docs/bmad-prompt.md`

## Rule for this repo

This repository is public. It holds code and generic specs only. Real names, family details, seed data, keys and exports never go in here; they live in Supabase or in local files covered by `.gitignore`.
